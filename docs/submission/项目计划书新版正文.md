## 1 项目概述

### 1.1 项目背景

随着移动终端摄影能力持续提升，普通用户拍摄照片的数量和频率大幅增加，但高质量图像创作仍然存在明显门槛。一方面，专业调色涉及曝光、对比度、色温、饱和度、曲线等多个维度，传统修图流程较为复杂，普通用户难以快速获得理想效果；另一方面，创作者在后期处理中往往需要在效率、质量和学习成本之间反复取舍，难以形成稳定、高效的创作流程。

近年来，人工智能技术在图像理解、参数推荐、自然语言交互和三维建模等方向快速发展，为移动端视觉创作工具带来了新的可能。相比传统滤镜式应用，AI 可以帮助用户理解画面内容、生成更贴近场景的调色建议，并通过语音或自然语言降低交互门槛。同时，2D 图像向 3D 内容延展的需求也在不断提升，用户不仅希望美化照片，还希望围绕照片开展更具创意的内容生产与分享。

基于以上背景，本项目选择以“智能照片调色”为核心切入点，围绕移动端创作场景，构建集 AI 首轮分析、语音调色、GPU 实时预览、2D 转 3D、社区分享于一体的创作辅助应用 VisionGenie，帮助用户以更低门槛完成从图片处理到内容表达的创作过程。

### 1.2 项目目的

本项目旨在开发一款面向普通用户和摄影爱好者的智能照片调色与创作辅助应用，通过移动端交互、云端 AI 服务和本地渲染能力的结合，实现以下目标：

（1）降低调色门槛。通过 AI 首轮建议与语音驱动交互，帮助用户在较短时间内完成具备审美方向的图像调整。  
（2）提升创作效率。通过 GPU 实时预览和参数联动，减少传统反复试错带来的时间成本。  
（3）拓展内容表达方式。在完成图片调色基础上，进一步提供 2D 转 3D 能力，增强作品延展性。  
（4）构建创作分享链路。通过社区模块支持作品发布、互动和沉淀，提升应用的持续使用价值。  
（5）探索 AI 在移动视觉创作中的落地路径。围绕调色、交互和内容生成建立完整原型，为后续优化和比赛展示提供可靠基础。

### 1.3 创新点

#### 1.3.1 技术创新点

（1）语音驱动的调色交互。项目将语音识别、指令解析与调色参数映射进行整合，使用户能够通过自然语言完成亮度、色温、饱和度等参数调整，减少传统滑杆调参的使用门槛。  
（2）AI 分析与本地 GPU 渲染协同。后端负责图像理解、调色建议和语义解析，前端借助 Skia 渲染引擎进行实时预览，实现“云端给建议、本地看效果”的协同创作体验。  
（3）调色创作与 3D 建模联动。项目不仅关注二维图片修饰，还将图像处理结果与 2D 转 3D 任务流程串联，为后续展示、传播和内容再创作提供基础。  
（4）统一模块化网关设计。后端采用模块化网关统一挂载调色、建模、AI Agent、社区和认证能力，便于后续扩展、测试与接口维护。

#### 1.3.2 功能创新点

（1）AI 首轮建议与手动精修结合。用户上传图片后可先获得基于场景分析的初始建议，再在专业调色面板中继续细化，兼顾智能化与可控性。  
（2）语音调色与专业参数并存。项目既支持普通用户通过口语化指令快速操作，也保留曝光、高光、阴影、色温、自然饱和度等专业参数，适配不同层次用户。  
（3）2D 转 3D 异步任务机制。建模任务采用异步处理与状态查询机制，适合对耗时较长的 3D 生成流程进行管理。  
（4）创作结果可直接进入社区链路。调色作品不仅停留在本地编辑阶段，还可以进入草稿、发布、点赞、收藏、评论等完整互动流程。

#### 1.3.3 其他创新点

（1）项目整体界面强调创作氛围感与轻量操作路径，兼顾视觉表达与功能密度。  
（2）系统从一开始即考虑真实演示需求，围绕移动端真机操作、后端接口联调、模块健康检查和测试用例逐步完善原型。  
（3）在功能设计上强调“核心能力先落地、扩展能力逐步优化”，避免只停留在概念展示层面，提高项目完成度与可信度。

## 2 技术方案

### 2.1 总体架构

本项目采用移动端应用与后端服务分离的架构。移动端负责图片导入、交互操作、实时预览、作品展示和用户界面组织；后端负责图像理解、语音解析、AI Agent 规划、2D 转 3D 任务管理、社区数据服务与账户认证。整个系统围绕“调色创作主链路”组织，并通过模块化方式保证功能之间既能协同又相对独立。

[图 1 系统总体架构图，待补充]

#### 2.1.1 后端服务架构

后端基于 Node.js 与 Express 构建，采用模块化网关形式统一管理多个业务模块，当前主要包含以下部分：

（1）账户与认证模块：负责用户注册、登录、个人信息读取与设置更新，采用 JWT 维护用户会话。  
（2）调色智能模块：提供首轮建议、语音调色解析、专业自动调色和分割相关接口，是当前核心能力之一。  
（3）建模模块：负责 2D 转 3D 任务创建、捕获会话、任务进度查询、模型资源获取等流程。  
（4）AI Agent 模块：负责自然语言任务规划、执行辅助和记忆存储，当前已具备基础链路，但效果仍在持续优化。  
（5）社区模块：负责社区动态、草稿、发布、点赞、收藏、评论等内容服务。

后端同时提供模块健康检查与能力查询接口，便于前端动态获取服务状态，为演示和调试提供支持。

[图 2 后端模块关系图，待补充]

#### 2.1.2 移动端应用架构

移动端基于 React Native 构建，以页面化与组件化方式组织应用结构。当前主要页面包括创建页、建模页、Agent 页、社区页和个人页，形成较清晰的底部导航入口。应用入口先经过登录认证，再进入主界面，使社区能力和个性化体验具备基本账户基础。

在交互层面，移动端负责完成：

（1）图片选择与导入。  
（2）调色参数控制与实时预览。  
（3）语音输入、文本输入与结果反馈。  
（4）建模任务发起、预览和资源查看。  
（5）社区浏览、互动和作品管理。  

前端同时通过 React Query 管理数据请求状态，通过 Zustand 管理应用中的部分运行时状态，使交互流程更稳定、界面反馈更及时。

[图 3 移动端主要界面入口图，待补充]

### 2.2 功能详述

#### 2.2.1 智能调色模块

智能调色模块是本项目的核心模块，围绕“低门槛上手 + 可继续精修”的思路设计，当前已实现以下能力：

（1）图片导入与预览。用户可从系统相册选择图片，进入调色工作区。  
（2）AI 首轮建议。后端结合图像上下文和场景信息，为用户提供初步调色方向与参数建议。  
（3）语音调色。用户可以通过自然语言方式输入类似“亮一点”“色温冷一点”“饱和度降低”等指令，系统会完成语义解析并映射到具体调色参数。  
（4）专业调色面板。当前可围绕曝光、对比度、高光、阴影、色温、饱和度、自然饱和度等参数进行精细控制，并支持继续扩展。  
（5）GPU 实时预览。前端通过 Skia 构建预览链路，使调色效果在移动端界面中即时可见，提升用户调参效率。  
（6）调色结果导出。应用支持将当前调色结果导出保存，方便后续展示或进入社区分享。

相较初赛版本的规划描述，新版文案更强调本项目已经落地的“AI 建议 + 语音交互 + 本地预览”主链路，不再将尚未成熟的高级功能表述为已完整实现。

[图 4 智能调色界面，待补充]

#### 2.2.2 2D 转 3D 模块

2D 转 3D 模块是项目的重要扩展能力，主要面向有进一步创作表达需求的用户。当前模块支持以下流程：

（1）上传图片并创建建模任务。  
（2）查询建模状态，显示任务所处阶段。  
（3）获取模型资源并进行预览。  
（4）支持围绕建模任务进行分享或下载等后续操作。  

项目当前采用异步任务机制来管理建模流程，这一设计能够适配 3D 生成任务耗时较长的实际情况。与此同时，现阶段该模块仍存在明显优化空间，例如生成等待时间较长、结果返回速度受外部服务影响较大等。因此在计划书中将其定位为“已形成可演示能力、仍需持续优化的关键扩展模块”更符合项目真实状态。

[图 5 2D 转 3D 界面，待补充]

#### 2.2.3 社区功能模块

社区模块承担作品展示、互动和内容沉淀的作用，是项目从“单一工具”走向“创作平台”过程中的重要组成部分。当前已完成的核心能力包括：

（1）用户登录注册。  
（2）社区动态流浏览。  
（3）按标签进行内容筛选。  
（4）作品详情查看。  
（5）点赞、收藏、评论等互动能力。  
（6）草稿保存与作品发布链路。  
（7）个人页中的作品与账户相关展示。

社区模块的加入，使调色结果不再局限于本地处理，而是具备“创作 - 展示 - 互动 - 反馈”的闭环基础。对于比赛展示而言，这也体现了项目从功能工具向应用生态迈进的方向。

[图 6 社区功能界面，待补充]

#### 2.2.4 AI Agent 模块

AI Agent 模块是项目在交互层面的探索方向，目标是让系统不仅能响应单个参数命令，还能理解更完整的创作意图，并辅助生成操作计划。当前阶段已完成的能力包括：

（1）自然语言输入与基础对话界面。  
（2）任务规划接口。  
（3）执行辅助接口。  
（4）记忆存储与查询能力。  
（5）与调色和建模上下文的基础联动。

需要如实说明的是，AI Agent 虽然已经具备基本链路，但当前整体表现尚未达到理想预期，尤其在复杂意图理解、计划稳定性与执行准确性方面仍有改进空间。因此在项目展示中，该模块更适合作为“正在持续优化的创新能力”而非完全成熟的核心卖点。

[图 7 AI Agent 界面，待补充]

#### 2.2.5 账户与个人中心模块

为支撑社区与个性化体验，项目增加了账户与个人中心相关能力，包括：

（1）注册、登录和令牌恢复。  
（2）用户资料读取与修改。  
（3）个人设置更新。  
（4）个人作品与创作记录承接。

这一部分虽然不直接构成项目的技术亮点，但为社区互动、作品管理与后续个性化推荐提供了必要基础。

### 2.4 系统界面与用户体验（UI/UX）

项目在界面设计上强调“创作氛围感、操作集中、反馈清晰”。整体界面采用较强的视觉层次与渐变背景，在保证美观性的同时突出主要交互区域。底部导航围绕创建、建模、Agent、社区和个人页展开，使不同功能入口清晰可见，降低用户在复杂功能之间切换的认知成本。

在调色场景下，系统通过大图区预览、参数分组、语音输入提示和错误反馈，尽量缩短用户从“导入图片”到“获得效果”的路径。在社区场景下，项目采用标签筛选、前后对比展示和卡片式动态流组织内容，使作品展示更适合比赛演示与真实使用。在建模场景下，界面强调任务状态、预览与资源获取顺序，尽量减轻用户对长等待过程的不确定感。

需要说明的是，当前 UI/UX 已具备较完整原型展示能力，但仍属于持续打磨阶段。后续仍可在操作引导、状态可视化和复杂任务反馈方面继续优化。

## 3 项目计划

### 3.1 可行性分析

#### 3.1.1 技术可行性分析

从当前开发状态看，项目核心链路已经具备较高技术可行性。

第一，智能调色主功能已完成基础打通。前端已实现图片导入、参数调节、实时预览和导出，后端已提供首轮建议、语音解析与相关调色接口，说明项目的核心能力并非停留在概念层面，而是已完成原型验证。  
第二，2D 转 3D 虽然耗时较长，但任务创建、状态查询和模型获取链路已经形成，说明该模块具备实际运行基础。  
第三，社区功能已经具备账户、动态流、互动和发布等能力，说明项目在应用层面已不仅是单点工具，而是具备基础内容体系。  
第四，项目拥有较完整的测试用例体系，覆盖前端页面、状态管理、语音链路、后端模块与接口契约，这为后续迭代提供了较强支撑。

当前技术风险主要集中在以下方面：

（1）AI Agent 对复杂意图的理解与规划效果仍需提升。  
（2）2D 转 3D 对外部服务依赖较强，生成耗时较长。  
（3）外部模型服务会受到网络状况、调用额度与响应稳定性的影响。  
（4）语音调色在不同设备与环境中的识别体验仍需进一步优化。  

针对上述风险，项目已通过模块健康检查、错误提示、异步任务管理、接口拆分和测试补充等方式降低不稳定因素，后续将继续围绕准确率、响应速度和交互可解释性展开优化。

#### 3.1.2 资源可行性分析

本项目由两名成员协作完成，分工明确：

A 负责智能调色与 AI Agent 搭建，重点承担调色主链路、语音调色逻辑和 Agent 相关能力设计与实现。  
B 负责 2D 转 3D 功能和社区搭建，重点承担建模流程、社区模块、账户链路及相关后端能力建设。

从资源角度看，项目采用的技术栈以 React Native、Node.js、SQLite 与第三方 API 为主，整体部署和联调成本可控；开发过程以移动端原型和本地/云端接口联调为主，对硬件要求相对适中，适合大学生团队在比赛周期内推进。项目当前已经形成可演示原型，说明现有资源投入能够支撑阶段性成果产出。

#### 3.1.3 市场可行性分析

在市场层面，移动影像工具需求长期存在，但大量产品要么偏娱乐滤镜，要么偏专业后期，普通用户往往缺少既具备一定智能化能力、又保持较低操作门槛的工具。VisionGenie 的价值在于以“智能调色”为核心切入，再通过语音交互、3D 扩展与社区沉淀形成差异化。

对于普通用户而言，项目能够帮助其更快捷地获得风格化图片；对于摄影爱好者和内容创作者而言，项目能够提供更高效的初步处理链路与创作表达空间。虽然当前产品仍处于原型优化阶段，距离商业化成熟产品还有差距，但其方向具备明确需求基础和进一步迭代空间。

## 4 总结与展望

### 4.1 总结与项目价值

VisionGenie 以智能照片调色为核心，围绕移动端创作场景构建了一个集 AI 建议、语音交互、实时预览、2D 转 3D 与社区分享于一体的应用原型。与旧版以规划性描述为主的文档相比，当前版本更加突出项目已经完成的实际能力，并对仍在优化中的部分作出真实说明。

本项目的价值主要体现在以下几个方面：

（1）在功能层面，项目已形成较完整的创作主链路，能够支撑比赛中的真机演示和功能说明。  
（2）在交互层面，语音调色和 AI 建议降低了普通用户使用专业调色能力的门槛。  
（3）在扩展层面，2D 转 3D 与社区模块拓宽了作品从编辑到传播的空间。  
（4）在工程层面，项目具备模块化后端、账户体系和测试基础，为持续迭代提供了良好支撑。  
（5）在研究与实践层面，项目展示了 AI 在移动视觉创作辅助中的一条可落地路径。

### 4.2 展望

未来，项目将继续围绕以下几个方向迭代：

#### 4.2.1 技术优化

进一步提升 AI Agent 的规划与执行质量，增强其在复杂创作任务中的可用性；继续优化 2D 转 3D 的任务效率与结果展示方式；完善语音调色的识别稳定性和指令覆盖度。

#### 4.2.2 功能扩展

在现有调色基础上继续扩展更丰富的风格模板、局部处理策略和用户偏好记忆能力；在社区侧逐步完善内容管理、互动反馈和创作者沉淀机制。

#### 4.2.3 用户体验提升

围绕比赛展示与后续使用体验，继续优化状态反馈、异常提示、页面动效和操作路径，让系统在复杂功能下依然保持较清晰的交互体验。

#### 4.2.4 平台与应用价值

项目后续可继续探索更完整的移动端部署与跨场景展示能力，在摄影爱好者、内容创作者和普通用户等群体中验证更明确的使用价值，并为后续商业化或产品化方向积累基础。

总体而言，VisionGenie 当前已经完成从概念设计到原型实现的关键跨越。虽然 AI Agent 效果和 3D 建模效率仍有待提升，但项目的核心能力已经具备较强展示性与继续迭代的空间，能够较真实地体现团队在智能视觉创作方向上的实践成果。
